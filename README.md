🎓 Student Information System Using Python

📌 Project Overview

The Student Information System is a simple, menu-driven Python application designed to manage student records efficiently.

This project allows users to add, view, search, and delete student information using a command-line interface.

It demonstrates fundamental Python programming concepts such as dictionaries, functions, loops, conditional statements, and user input handling.

🚀 Features

✅ Add Student – Add student details, including Roll Number, Name, and Department.

✅ View Students – Display all available student records.

✅ Search Student – Search for a student using their Roll Number.

✅ Delete Student – Remove a student record using their Roll Number.

✅ Exit – Safely exit the application.

🛠️ Technologies Used

- Programming Language: Python 3
- Development Environment: VS Code / Any Python IDE
- Interface: Command-Line Interface (CLI)
- Data Structure: Python Dictionary

⚙️ How to Run

Step 1: Install Python 3 on your computer.

Step 2: Download or clone this repository.

Step 3: Open the project folder in VS Code or a terminal.

Step 4: Run the Python program.

python main.py

Step 5: Select an option from the menu.

🧠 Python Concepts Implemented

This project demonstrates:

- Dictionaries: Store and manage student information.
- Functions: Organize the program into reusable components.
- While Loops: Continuously display the menu until the user exits.
- Conditional Statements: Execute operations based on user choices.
- User Input: Accept student information interactively.
- Dictionary Methods: Access and display stored student records.

📌 Important Note

Student records are stored temporarily in a Python dictionary.

The information will be lost when the program terminates because permanent file storage or database integration has not been implemented.
